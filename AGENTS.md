## Architecture

The program is a MinGW C++20 window. Configure and build with the `mingw` or `mingw-release` preset on Windows, or the `mingw-wsl` or `mingw-wsl-release` preset on WSL. Keep the console subsystem. The `mingw-release` and `mingw-wsl-release` presets link `tdms_viewer` with `-static`, so that executable does not depend on `libstdc++-6.dll`, `libgcc_s_seh-1.dll`, or `libwinpthread-1.dll`.

The window stack is GLFW 3.3.8, OpenGL 3, GLSL 130, Dear ImGui `v1.92.4`, and ImPlot `v1.0`. Those are the versions in the FetchContent example shipped with ImPlot v1.0. ImGui is built with `backends/imgui_impl_glfw.cpp` and `backends/imgui_impl_opengl3.cpp`. GLFW docs, tests, examples, and install stay off.

TDMSpp is commit `67a22fd35129ae7d21698c1083cd73db7bd10527`. FetchContent adds only its `src` directory, which defines the `tdmspp` target. The public include directory is `${tdmspp_SOURCE_DIR}/src`. The clone sets `core.autocrlf` to false, then FetchContent runs `git apply` on `cmake/tdmspp.patch`. That patch changes the one `fopen` in `src/tdms_file.cpp` from `"r"` to `"rb"`. It also clones inherited segment objects in `src/tdms_segment.cpp` and declares that clone in `src/tdms_impl.hpp`, so a later segment cannot change an earlier segment's sample count. Do not apply other TDMSpp changes.

File > Open is the Win32 common dialog (`GetOpenFileNameA`, `comdlg32`), owned by the GLFW window. Filters are `*.tdms` and all files. The path is a narrow string because `TDMS::file` passes it to `fopen`. The GLFW window is created with the title `tdms_viewer`. A successful load sets that title to `tdms_viewer - ` followed by the opened path. A failed load leaves the title unchanged.

`TDMS::file` owns the channel bytes the plot reads. A failed load shows `std::exception::what()` in the window and keeps the previous capture. A successful load replaces the capture and clears the selection and the stored range.

The left pane lists every object from `TDMS::file`, labeled with `get_path()`. The right pane shows the selected object's path, `data_type()`, and `number_values()`. ImPlot draws the selected channel as one line against the sample index, and only for `tdsTypeI8`, `tdsTypeI16`, `tdsTypeI32`, `tdsTypeU8`, `tdsTypeU16`, `tdsTypeU32`, `tdsTypeU64`, `tdsTypeSingleFloat`, and `tdsTypeDoubleFloat`. Float and double are plotted from `data()` in place. Integers are copied to `double` when the selection changes. A count that does not fit in ImPlot's `int` is not plotted.

Do not plot other types. `tdsTypeI64` is stored by `put_le_on_heap_generator<int32_t>()` into an 8-byte value, so it is not the file's int64 data. TDMSpp timestamp reading is a stub. String, boolean, extended float, unit-wrapped floats, big-endian, interleaved, and DAQmx raw data are unimplemented and can make `TDMS::file` throw.

View > Reset fits both axes to the whole channel. View > Set Range opens a dialog titled `Set Frame`, with Start frame and Stop frame text boxes. Those are inclusive 0-based sample indices. The boxes start at the sample indexes nearest the current X-axis minimum and maximum. A halfway value rounds away from zero. Each index is clamped to 0 through the last sample. If the plot has not finished a frame, or either limit is not finite, the boxes start at 0 and the last sample. OK sets the X axis to that range and the Y axis to the finite samples in that range, and stores the channel path with those inclusive indexes. The stored indexes are the typed start and stop, not the axis limits after a flat range is expanded. The full channel is still drawn. A range whose minimum equals its maximum is expanded by 0.5 on both sides. Invalid text, a start after stop, an index outside the channel, or a range with no finite sample leaves the view and the stored range unchanged, keeps the dialog open, and shows `Start and stop must be whole numbers from 0 through the last sample, and start must not be after stop.` Cancel closes the dialog and leaves the view unchanged. Each action applies for one frame; pan and zoom still work afterward. The mouse wheel over the plot zooms both axes toward the pointer. Holding Ctrl while scrolling the wheel scales the Y axis around zero and leaves the X axis unchanged. Scroll up zooms in. Pan, zoom, and this scale do not change the stored indexes. Reset and Set Range are enabled only when the selected channel is plotted. Changing the selection does not clear the plot limits or the stored range. A successful load clears the stored range with the selection. A failed load keeps it.

View > RMS is a check after Set Range. It is enabled only when the selected channel is plotted. Turning it on opens a modal dialog titled `RMS` with a Window length box. The box starts at the last accepted length, or `1` when none has been accepted. OK accepts a positive whole number that fits in `int`, trimmed the same way as the Set Frame boxes. That length is stored and the overlay turns on. Any other text leaves the dialog open, leaves the overlay off, leaves the stored length unchanged, and shows `Window length must be a positive whole number.` Cancel closes the dialog and leaves the overlay off. Choosing RMS while it is on removes the overlay and does not open the dialog. The stored length is kept.

The overlay is a second line labeled `RMS`. ImPlot assigns it the next default colormap color. No line color is set in the viewer. Each point is the standard RMS of a centered window, the square root of the mean of the squares, with the window mean left in. For a length `N`, center `i` uses samples from `i - N/2` through `i + (N - 1)/2`, with integer division, so an even `N` has one extra sample before the center. The point is kept only when that whole window lies inside the sample indexes on the current X axis. Index `i` is inside when it is a valid sample and `x_min <= i <= x_max`. Those limits are `ImPlot::GetPlotLimits()` after the channel line is drawn. Float and double samples are read from `data()`. Integer samples are read from the double plot copy. A window that contains a non-finite sample is omitted. Kept points are plotted at their sample indexes and connected in that order. When the viewed indexes are shorter than `N`, or no point is kept, the `RMS` line and its legend entry are not drawn. The sum of squares slides in `double`. A negative accumulated sum is treated as zero before the square root.

Set Range still sets Y from the finite samples in the typed range, so an RMS value outside that span is clipped until the user pans, zooms, or uses Reset. Reset and the first fit include the RMS points, so a channel whose samples are negative can extend the fitted Y axis up to the RMS curve. Pan, zoom, and the Ctrl wheel scale do not change the stored window length. A successful load, a failed load, and a selection change do not clear the check or the stored length. The line is drawn only for a plotted channel.

View > AVG(ABS(Y)) is a check after RMS. It is enabled only when the selected channel is plotted. Turning it on opens a modal dialog titled `AVG(ABS(Y))` with a Window length box. The box starts at the last accepted length for this overlay, or `1` when none has been accepted. OK accepts a positive whole number that fits in `int`, trimmed the same way as the Set Frame boxes. That length is stored and the overlay turns on. Any other text leaves the dialog open, leaves this overlay off, leaves its stored length unchanged, and shows `Window length must be a positive whole number.` Cancel closes the dialog and leaves this overlay off. Choosing AVG(ABS(Y)) while it is on removes the overlay and does not open the dialog. The stored length is kept. The RMS check and its length stay independent.

The overlay is a line labeled `AVG(ABS(Y))`, drawn after the channel line and after the RMS line when that overlay is on. ImPlot assigns it the next default colormap color. No line color is set in the viewer. Each point is the mean of the absolute samples in a centered window. For a length `N`, center `i` uses samples from `i - N/2` through `i + (N - 1)/2`, with integer division, so an even `N` has one extra sample before the center. The point is kept only when that whole window lies inside the sample indexes on the current X axis. Index `i` is inside when it is a valid sample and `x_min <= i <= x_max`. Those limits are `ImPlot::GetPlotLimits()` after the channel line is drawn. Float and double samples are read from `data()`. Integer samples are read from the double plot copy. A window that contains a non-finite sample is omitted. Kept points are plotted at their sample indexes and connected in that order. When the viewed indexes are shorter than `N`, or no point is kept, the `AVG(ABS(Y))` line and its legend entry are not drawn. The sum of absolute values slides in `double`. A negative accumulated sum is treated as zero before dividing by `N`.

Set Range still sets Y from the finite samples in the typed range, so an average outside that span is clipped until the user pans, zooms, or uses Reset. Reset and the first fit include these points along with any RMS points. Pan, zoom, and the Ctrl wheel scale do not change the stored window length. A successful load, a failed load, and a selection change do not clear this check or its stored length. The line is drawn only for a plotted channel.

Tools > Duration is a check in the Tools menu, after View. It does not open a dialog. It is enabled when the selected channel is plotted and that channel's `wf_increment` is usable, and also when Duration is already on, so it can be turned off. `wf_increment` is usable only when that property is on the selected channel, not on a parent group, its type is `tdsTypeDoubleFloat` or `tdsTypeSingleFloat` with that type's stored size, and the value is finite and greater than 0. Turning Duration on leaves the plot limits, the stored range, RMS, and AVG(ABS(Y)) unchanged and starts with no markers. Turning it off clears the markers. A successful load clears the markers with the selection and leaves the check as it was. A failed load keeps the check and the markers. Changing the selection does not clear the markers.

While Duration is on, a left-button release sets a marker only when the plot is hovered, the press and the release are both inside the plot, and the movement stays within ImGui's drag threshold. A drag still pans. The mouse wheel and the Ctrl wheel keep their current zoom. The marker is the finite sample whose plotted point is closest to the click in screen pixels. The search starts at the nearest index and stops when a farther index cannot be closer. If two samples are the same distance, the lower index is kept. A click with no finite sample is ignored. Float and double samples are read from `data()`. Integer samples are read from the double plot copy. The point is drawn at that sample's index and value. The plot X axis stays the sample index. Timestamp values are not read.

The first click stores the start index on the selected channel path. A second click on that same path stores the end index, including a click on the same sample. Further clicks on that path do nothing until Duration is turned off. A click on a different plotted channel that has a usable `wf_increment` replaces the stored path and becomes the new start. If the selected channel has no usable `wf_increment`, clicks do nothing.

Until the end index is stored, the plot draws that one point at the snapped sample, with no legend entry and no time text, and that point is not included in Reset or the first fit. With both indexes stored, and only while Duration is on, the selected path is the stored path, and `wf_increment` is usable, ImPlot draws both points and a line between them labeled `Duration`. The points are circle markers at those samples. ImPlot assigns the line the next default colormap color. No line color is set. The line and its points are not included in Reset or the first fit. If either sample is non-finite when the plot is drawn, the points and the line are not drawn. The time is the absolute difference of the two indexes times `wf_increment`, in seconds, so click order does not change it. An annotation at the midpoint of the two points shows that time, clamped inside the plot. The text color is the current ImGui text color. That annotation is the only duration readout. When `wf_increment` is not usable, the points and the duration line are not drawn.

The unit is chosen from the seconds value before formatting. At 60 seconds and above the unit is `min`. At 1 second and above it is `s`. At 0.001 seconds and above it is `ms`. At 0.000001 seconds and above it is `us`. Below that, including 0, it is `ns`. The number is `%.6g` of the value in that unit, then a space, then the unit. A value just below a cut can print as 1000 of the smaller unit. The unit is not promoted after rounding.

File > Export Range and File > Export Range to CSV are enabled only when the selected plotted channel is the stored path. Both open a Win32 save dialog (`GetSaveFileNameA`, `comdlg32`), owned by the GLFW window. The path is a narrow string. Cancel leaves the capture, the stored range, and the error text unchanged. Export Range filters are `*.tdms` and all files, and the default extension is `tdms`. Export Range to CSV filters are `*.csv` and all files, and the default extension is `csv`. The flags are `OFN_OVERWRITEPROMPT`, `OFN_PATHMUSTEXIST`, and `OFN_NOCHANGEDIR`.

Export Range writes one little-endian segment, version 4712, with metadata, a new object list, and raw data. The file contains `/` and each group prefix of the channel path, with no samples and no properties, then the channel at its original path and data type. Samples are the inclusive stored range, copied from `data()` at the native element width. Integer samples are not taken from the double plot copy. Channel properties are written in `std::map` name order. String properties and `tdsTypeI8`, `tdsTypeI16`, `tdsTypeI32`, `tdsTypeU8`, `tdsTypeU16`, `tdsTypeU32`, `tdsTypeU64`, `tdsTypeSingleFloat`, and `tdsTypeDoubleFloat` properties are written little-endian. Strings are a length plus bytes. Any other property type, including `tdsTypeI64` and `tdsTypeTimeStamp`, writes no file and shows `This channel has a property that cannot be exported unchanged.` A channel path that is not `/` or a `/`-separated sequence of single-quoted names writes no file and shows `Channel path cannot be exported.` A range outside the channel, or a channel type that is not one of those numeric types, writes no file and shows `The sample range cannot be exported.` The bytes are built in memory and written once. A failed open shows `File "<path>" could not be opened`. A failed write shows `File "<path>" could not be written`. Either failure leaves the capture and stored range in place. Success clears the error text.

Export Range to CSV uses the same enable rule, range checks, and error text. The file has no header. Each sample is one line ended by `\n`. Integers are decimal integers from the native sample. Finite float and double use `std::to_chars` general format with `std::numeric_limits::max_digits10`. Non-finite values are `nan`, `inf`, and `-inf`.

An empty capture says there are no objects. With no channel selected, the plot pane says to select a channel.
